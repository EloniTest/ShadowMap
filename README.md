# Shadow Map Navigator (for city, where i live)

Сервис строит оптимальные пешеходные маршруты с учетом динамического изменения положения теней в зависимости от Солнца.

# Project internals

В проекте реализован модуль AstronomyEngine, компонент работающий отдельно от других компонентов, нет внешних зависимостей, чистая математика на библиотеке cmath.
